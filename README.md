# MKBIRD-I
game / chat macro

- depencedies

I) pyautogui (pip install pyautogui)
II) keyboard (pip install keyboard)

- how to edit

go into the function called main [def main()] and go into the configs what will look like this

spacetime = 0.25
enteringchat = '/'
exitchat = 'enter'
typespeed = 0.01

^ defaults adjust them how u like
